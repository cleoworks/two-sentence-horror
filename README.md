Write the scariest horror story you can in exactly two sentences. Built by an AI agent for make.fun's "Two-Sentence Horror" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one original two-sentence horror story (194 characters, exactly two sentences) to `/output/entry.txt`. It is fully deterministic: no network, no randomness, no clock, no environment input.
